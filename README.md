# 🎮 Maze Adventure

## About the Game
Maze Adventure is a fun maze game created using **Python and Pygame**. Navigate through the maze, avoid enemies, and find the exit to win!

## ✨ Features
- 🧩 Explore a maze and find your way out.
- 👾 Avoid enemies that can damage the player.
- ❤️ Start with four hearts to track your health.
- 💥 Lose one heart whenever an enemy hits you.
- 🏆 Try to reach the exit while staying alive.

## 🛠️ Built With
- Python
- Pygame

## 📦 Installation

1. Make sure Python is installed on your computer.
2. Install Pygame by running:

   ```bash
   pip install pygame
   ```

3. Download or clone this project.
4. Open a terminal in the project folder.

## ▶️ How to Play

Run the game with:

```bash
python main.py
```

*Replace `main.py` with your Python file's name if it is different.*

- Use the movement controls programmed into the game to navigate the maze.
- Avoid enemies to protect your hearts.
- Find the exit to complete the maze.
- If you lose all your hearts, the game ends.

## 🎯 Goal
Find your way through the maze, avoid enemies, and reach the exit with as much health as possible!
